Keymaps

All keymaps use "< leader >".

_* Leader key = [ SPACE ] *_

---

📁 Explorer

* < leader > ex    Focus file explorer

---

🔍 Search

* < leader > ff    File search
* < leader > fg    Project search

---

✂️ Selection

* < leader > sa    Select all
* < leader > sw    Select word
* < leader > sl    Select line
* < leader > sp    Select paragraph
* < leader > sb    Select block
* < leader > sf    Select function
* < leader > sc    Select class

---

🧠 LSP

* < leader > lr    Rename symbol
* < leader > la    Code action
* < leader > dd    Show diagnostics (float)
* < leader > dt    Toggle diagnostics virtual text

---

🐞 Debug

* < leader > d     Debug actions (DAP)
* [d               Previous diagnostic
* ]d               Next diagnostic

---

🚀 Run / Test

* < leader > r     Run current file / project
* < leader > t     Run tests
* < leader > tn    Run nearest test

---

🖥️ Terminal

* < leader > Ts    Shell terminal
* < leader > Tr    Run terminal
* < leader > Tt    Test terminal
* < leader > Tg    Open lazygit

---

🎨 UI

* < leader > uc    Change color scheme
* < leader > ut    Toggle transparency
* < leader > ul    Toggle layout (IDE / Zen)
