UNIVERSAL STYLE GUIDE (USG)
===========================

Defines how code and documentation are written and formatted.

---

PURPOSE
-------

Ensure code is:

- Readable
- Consistent
- Beginner-friendly

---

DOCUMENT STRUCTURE & DIVIDERS
-----------------------------

MAIN HEADERS

- Use "=" underline

Example:

HEADER
======

---

SUBSECTIONS

- Use "-" underline

Example:

SECTION
-------

---

RULES

- "=" only for main headers
- "-" only for subsections
- No mixing styles
- No custom dividers

---

FILE HEADER
-----------

Every file must include:

- Purpose
- Why it exists
- How it works
- Flow
- Beginner notes

---

NAMING
------

Files:

- lowercase-with-dashes

Variables:

- descriptive names

Functions:

- verb-based

---

FINAL RULE
----------

Write for beginners.
