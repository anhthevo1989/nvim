# 🌙 NeoVibe

> ✨ A minimal, expressive, and beginner-friendly Neovim experience.

NeoVibe is a carefully crafted Neovim configuration designed to balance **clarity**, **consistency**, and **power**—without overwhelming users.

---

# ✨ Philosophy

NeoVibe is built on a few core principles:

* 🧩 **Minimal but expressive**
  Only what you need, but done well.

* 🧭 **Consistency over cleverness**
  Predictable structure across the entire codebase.

* 🌱 **Beginner-friendly**
  The config should teach, not confuse.

* 🎨 **Cohesive design**
  A unified look and feel (Dark Pulse theme).

---

# 🚀 Features

* ⚡ Neovim core
* 🧠 LSP support
* 🌲 Treesitter
* 💡 Autocompletion
* 🌿 Git (LazyGit)
* 🔍 Search & navigation
* ⌨️ Keymap system
* 📦 Plugin system
* 🖥️ Terminal integration

---

# 📦 Installation

```bash
curl -fsSL <your-install-url> | bash
```

Then run:

```bash
neovibe
```
